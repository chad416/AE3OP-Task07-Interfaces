# AE3OP Task 07 - Interfaces

This console application completes the Interfaces tutorial. It demonstrates:

- a shared `IAnimal` contract implemented by unrelated classes;
- interface properties and methods through `ICharacter` and `ICombatant`;
- polymorphism with `Warrior` and `Mage`;
- interface inheritance and multiple interface implementation;
- explicit implementation of two conflicting `Attack()` members.

Run it with:

```powershell
dotnet run
```
